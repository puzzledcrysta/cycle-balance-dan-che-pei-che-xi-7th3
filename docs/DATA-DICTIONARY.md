# 单车配车席数据字典

## 来源文件

| 字段 | 定义 |
|---|---|
| 调车区 | 文本主键，保留前导零。跨业务键不汇并记录。 |
| 修订号 | 正整数。最高版优先；最高同版字段冲突或存在同版、更新版的未采信记录时隔离，旧版无法接替。 |
| 提交时间 | ISO 8601，必须带 UTC 偏移量。标准化后展示 UTC。 |
| 原始备注 | 可空，允许引号内换行。 |
| 站点余缺、可行车路 | 必填字段。多项字段用半角分号隔开，显式空集合用 `无`。 |

识别 `UTF-8`、UTF-8 BOM 与独立的 `GB18030` 文件。`业务编号`、`版本`、`更新时刻`、`备注` 为旧版表头别名。新旧名同时出现会被拒绝。`-`、`N/A`、`NULL`、`未知` 和空串均按必填值缺失处理。物理行号指 CSV 逻辑记录起始行。

## 计算字段

余缺写 `站名:有符号数量`，正数为供给。车路写 `起点>终点:容量:公里数`，允许通过中转站。

先保证最大调出量，再在这批数量上最小化车公里。需走反向残量边时会撤销先前选择。

数值在服务端以十进制定点方式计算，对外按字符串传输。单文件上限 128 KiB，复合字段最多 240 个项目，个别字段还有业务上限。格式无法恢复的 CSV 整批拒绝，列数、缺字段、来源冲突和业务条件错误逐条隔离。

## 复算与外部清单

外部清单包含 `调车区` 和 `外部记录值(车公里)`，允许省略不在对账范围内的键。同一键重复会拒绝该清单。结果数值单位为 **车公里**。差值按本次复算减外部记录，缺一侧时差值计算以 0 占位并保留缺失原因。

同一对输入字节与规则版本生成同一批次，导出包含两个文件摘要、证据行、单边差异和复核修订记录。复核保存前检查当前版本，在有隔离、差异或退回时必须填写意见。

## 班次交接（M5b）

早班交接在七点前完成，部分到达记录七点半后才回传。交接不等待全部记录，也不把预估与确认混算，而是以**交接截止时刻**为界分两套口径。

### 三份输入

| 文件 | 表头 | 说明 |
|---|---|---|
| 期初余额 `opening.csv` | 调车区、站点、期初车辆 | 同区同站重复登记隔离（`HANDOVER_DUP`）。 |
| 发车单 `departure.csv` | 调车区、调车单号、起点、目标站、数量、发车时刻、预计到达 | 调车单号全局唯一；ETA 早于发车、起终点相同均隔离。 |
| 到达/取消事件 `events.csv` | 调车区、调车单号、事件类型、提交时间、事件时刻、到站 | 事件类型仅 `到达`/`取消`；允许只有表头（本班无回传）。 |

截止时刻 `cutoff` 可显式提交（带 UTC 偏移）；留空时取最早发车日的 `07:00 +08:00` 并归一到 UTC。

### 双口径与状态机

- **已确认到站**：到达记录的**提交时间**不晚于截止时刻，进入确认余额（`inflow`）。
- **在途预计**：已发车且无有效到达记录；按发车单 ETA 仅计入 `projected_inflow`，**不进确认口径**，因此目标站不会对同一批车重复占位，起点流出也只算一次。
- **已取消**：取消事件早于发车时刻为发车前取消，车未离站、不产生移动；否则为发车后取消，冲销发车流出并把车退回起点（`returns`），确认余额净变化为 0。
- 到达记录提交时间晚于截止时刻（如七点半回传）进入 `unreceived`，车辆仍按在途处理；同事件重传记 `EXACT_DUP` 抑制；到站与目标站不符、非法状态转移、幽灵调车单、跨调车区事件逐行隔离。

站点 `confirmed_balance = 期初 + 确认流入 - 流出 + 取消退回`，`projected_balance = 确认余额 + 在途预计流入`。余缺正数为余、负数为缺，下一班只照**确认口径**派车，预测口径仅作参考。车辆守恒恒为 `期初 = 确认在库 + 在途`。

### 结转幂等

交接指纹由三份文件字节、截止时刻与规则版本 `shift-handover-1.0` 共同哈希得到，落库 `handover_runs` 用 `INSERT OR IGNORE`。同一班次重新运行返回同一快照、只保留一行，结转不重复；截止时刻或输入变化才产生新快照。
